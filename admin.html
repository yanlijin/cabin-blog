写作台

在这里写文章、改站点信息，点一下「保存并发布」，改动会直接提交到你的 GitHub 仓库，Netlify 一分钟后自动更新。

  1. 打开 创建令牌页面（已帮你勾好权限）
  2. 最下面点 Generate token，复制生成的 ghp_…
  3. 粘贴到下面，勾选「记住」，以后就不用再输了

令牌只保存在你浏览器的 localStorage，不会发到任何地方，除了直接提交给你自己的 GitHub。 它相当于仓库的写权限密码，别截图分享；不想用了就去 GitHub 设置里删掉。
